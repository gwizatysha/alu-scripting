# api_advanced

Python scripts that query the Reddit API (https://www.reddit.com).

- `0-subs.py`: returns the number of subscribers of a subreddit (0 if invalid)
- `1-top_ten.py`: prints the titles of the first 10 hot posts (None if invalid)
- `2-recurse.py`: recursively returns a list of all hot post titles
- `3-count.py`: recursively counts keywords in all hot post titles

Requires Python 3 and the `requests` module.
